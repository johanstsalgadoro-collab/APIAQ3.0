# APIAQ · Presentación final web

Presentación interactiva del proyecto **Monitor de Calidad del Aire** para Electiva I - Python, Universidad ECCI.

## Contenido

- 21 diapositivas responsivas.
- Navegación con teclado, mouse y controles inferiores.
- Animaciones CSS y partículas de fondo.
- Evidencias reales del proyecto.
- Arquitectura, Scrum, ODS, producto final y repositorios.
- Bloque detallado de Python.
- Anexo interactivo con **más de 50 funciones/métodos** del backend y su propósito.

## Abrir localmente

Puedes abrir `index.html` directamente o usar un servidor local:

```bash
python -m http.server 8080
```

Luego abre `http://localhost:8080`.

## Controles

- `←` / `→`: diapositiva anterior / siguiente.
- `Espacio`: siguiente diapositiva.
- `Home` / `End`: inicio / final.
- Botón `☰`: índice.
- Botón `⛶`: pantalla completa.
- En las diapositivas de Python, botón **Ver catálogo completo de funciones Python**.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo.
2. Sube todo el contenido de esta carpeta a la raíz.
3. En GitHub: **Settings → Pages**.
4. En *Build and deployment*, selecciona **Deploy from a branch**.
5. Rama `main`, carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere la URL pública.
